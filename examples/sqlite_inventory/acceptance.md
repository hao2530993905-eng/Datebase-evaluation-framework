# 参考项目 Gold 依据

此文件是参考项目的需求与数据库设计依据，不是当前运行结果的转抄。

- 商品 SKU 必须唯一，价格和库存不得为负数。
- 订单状态只能是 `pending`、`paid` 或 `cancelled`，客户邮箱必须具有基本邮箱结构。
- 订单项数量必须大于零，订单项必须引用有效订单和商品。
- 删除订单时，其订单项必须级联删除。
- 产品列表按价格降序、SKU 升序稳定排序。
- 数据库 Schema 版本为 1，外键约束启用。
- 备份恢复后，商品总数和库存总数必须与备份时一致。
- 基础 SQL 测试不得通过参数拼接执行不可信值；只读连接不得成功写入。

参考项目的规范场景只覆盖数据库和 SQLite 连接层。它的 `application_api` 与
`orm` 特性声明为 `false`，因此不能据此宣称验证了应用 API 或 ORM 映射。
